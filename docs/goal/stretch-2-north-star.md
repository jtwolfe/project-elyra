## Goal

A durable, multi-regime **atomized memory substrate**: instances (atoms), temporal scaffold, weave of connections, consolidation into higher-scale structure, and later success-weighted pathways — not a warehouse of detached facts.

This substrate later supports self-improvement workflows. Those integrations stay **out of scope** until memory phases are solid.

## Phase goals (only)

| Phase | Focus | Care |
|-------|--------|------|
| **1** | Temporal / episodic foundation + meal spine | Stand alone without vectors |
| **2** | Semantic / Nemotron / vector search | Portability + freshness + product-path honesty |
| **2a** | Directed traversal | Temporary context hygiene |
| **3** | Procedural / success-path | Evaluation-first; experimental for v0.1 ([v0.1.md](v0.1.md)) |

**Honesty rule:** execute-plan complete ≠ product target. Prefer dogfood + default-off flags until operator sign-off.

## Memory regimes (intent)

| Regime | Role in context meal |
|--------|----------------------|
