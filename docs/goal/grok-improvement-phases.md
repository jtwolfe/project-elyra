## Phase overview

| Phase | Focus |
|-------|--------|
| **0** | xAI/Grok provider path, hierarchical usage meter, UI status/controls — **no MC implementation** |
| **After 0 stable** | **Stage B MC (MC-beta):** soft bias + Decide cadence + speak vocabulary (no new package) |
| **1** | `grok_build` tool + self-improve scaffolding |
| **2** | Self-modification continuity (worktree, verify, promote, controlled restart) |
| **3** | Atomized memory substrate as peer to MC (overlaps Stretch 2; see [stretch-2-north-star.md](stretch-2-north-star.md)) |

**Stage C** (optional MC package) is not a numbered Grok phase and is **not** the default next step.

## Guiding principles (short)

1. Do-loop and presence first — do not rebuild memory before model path and usage controls are correct.  
2. Correctness over scope — small, testable, reversible.  
3. Subscription protection — never burn the full SuperGrok weekly quota under normal operation.  
4. Person / instrument separation — Elyra is the person; Grok Build is the coding instrument.  
5. Hybrid Decide — soft MC surface; hard host policies stay where they are.
