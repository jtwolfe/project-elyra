# Rest

Sometimes the right action is no action.

## First action

Honest idle is success: if why-now shows nothing useful, **stop with no tools**.
Do not invent busywork or open empty goals.

- If this wake is social by mistake: `load_skill("talk")` then `speak`.
- Never treat free-text planning as work when rest is correct.

## Steps

1. Confirm why-now: no user message requiring a reply, no ready task you should take, no urgent timer work.
2. Do **not** invent busywork or open empty goals to look active.
3. If the wake was social by mistake, switch to `talk` and speak.
4. Otherwise stop with no tools (or only a quiet ledger note if the product expects heartbeat bookkeeping).

## Rules

- Silent exit is correct for pure work/background wakes with nothing ready.
- Never stay silent on social wakes (see `talk`).
- Rest is honest idleness, not avoidance of a clear ready task.
